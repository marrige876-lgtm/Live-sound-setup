# Live Sound Console – Android app

WebView wrapper that bundles your HTML (app/src/main/assets/index.html). Landscape, fullscreen, keeps screen on, microphone/camera permission prompts supported.

## Get the APK
**Option A – GitHub (no install):** create a new GitHub repo, upload this folder's contents, open the Actions tab > "Build APK" > Run workflow. Download `LiveSoundConsole-apk` > app-debug.apk, copy to phone, install (allow "unknown sources").

**Option B – Android Studio:** File > Open this folder > Build > Build APK(s).

Note: Google Fonts load online; offline the app falls back to system fonts.
